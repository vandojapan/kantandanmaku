# 追加サンプル

以下は、各タイトルでよく見られる発射原理をこのフィルタの共通ランタイム向けに単純化した学習用スクリプトです。原作のデータを抽出したものでも、特定パターンを完全再現したものでもありません。

- `touhou_rotating_ring.rhai`: 東方Project風の回転全方位弾
- `dodonpachi_daioujou_aimed_fan.rhai`: 怒首領蜂大往生風の高速自機狙い扇＋速度差
- `mushihimesama_spiral_layers.rhai`: 虫姫さま風の螺旋全方位弾＋速度差

使用する場合はファイルの内容をAviUtl2の「カスタムスクリプト」へ貼り付け、スクリプトモードを「カスタム」にしてください。
