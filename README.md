# 弾幕生成フィルタ（kantandanmaku）

AviUtl2の入力オブジェクトを1発の弾として複数回描画する、`.auf2`形式の弾幕スクリプトフィルタです。独自の弾画像は生成せず、図形・画像・テキストなど、フィルタへ渡されたオブジェクト画像をそのまま複製します。

## 構造

```text
入力オブジェクト
  → .auf2フィルタ
  → 弾幕スクリプトを評価
  → 現在時刻からBulletStateを直接計算
  → 入力画像を各座標へ描画
```

`aviutl2-rs 0.46.1`で確認したAPIを使用しています。

- `FilterPlugin::proc_video`: フィルタの映像処理
- `FilterProcVideo::object.time`: エフェクト全体の現在時刻
- `ImageResource::Object`: フィルタへ入力された現在のオブジェクト画像
- `FilterProcVideo::draw_image`: 入力画像の複数座標への描画
- `FilterProcVideo::set_default_anchor`: `draw_image`で出力を構築するフィルタのアンカー設定

発射原点は、現在の入力オブジェクトのアンカーをローカル座標 `(0, 0)` として扱います。ターゲット座標と描画座標も同じローカル座標系です。

## フェーズ2: Bullet / Wave / Timeモデル

弾の位置は前フレームの状態を更新せず、現在時刻から毎回直接計算します。

```text
wave       = floor(t / interval)
spawn_time = wave * interval
age        = t - spawn_time
position   = f(t, wave, age, i, seed, parameters)
```

寿命上限と発射間隔から、現在も生存し得るWaveだけを逆算して列挙します。開始時刻0から全Waveを走査しません。ランタイムは前フレームの弾状態や乱数状態を保持しないため、途中フレームからの評価と逆シークでも同じ時刻は同じ結果になります。

自動テストでは次を確認しています。

- 0秒付近から順番に評価した後と、対象時刻を直接評価した結果が一致する
- 後方の時刻から逆向きに評価した後も結果が一致する
- 現在Waveと過去Waveの `age` が `t - spawn_time` と一致する
- `wave_at(1.05, 0.2)` がWave 5、発生時刻1.0秒、age 0.05秒になる

- プリセット: `自機狙い奇数5方向` / `角度量子化自機狙い` / `速度差リング` / `混成弾幕`
- ターゲット X / ターゲット Y
- 自機座標モード / 自機レイヤー
- 発射間隔
- シード
- 進行方向を向く
- カスタムスクリプト

ターゲット X / Yと発射間隔はトラックバー項目なので、AviUtl2側でキーフレーム制御できます。

## フェーズ3: スクリプトエンジン

カスタムスクリプトは文字列として「カスタムスクリプト」欄へ入力します。フィルタの映像評価時にコンパイル・評価するため、DLLを再ビルドせずにロジックを差し替えられます。

```rhai
spawn {
    count = 1;
    angle = aim();
    speed = 420;
    life = 6;
}

motion {
    pos = polar(angle, speed * age);
    x = origin_x + pos.x;
    y = origin_y + pos.y;
}
```

`spawn`では `i`、`count`、`wave`、`t`、`origin_x`、`origin_y`、`target_x`、`target_y`、`seed` を参照でき、`count`、`angle`、`speed`、`life` を設定します。`motion`ではこれらに加えて `age`、`angle`、`speed`、`life` を参照し、`x`、`y` を設定します。

スクリプトはRhaiの演算回数上限で実行します。構文エラー・実行時エラー・不正値はそれぞれ `Parse Error（構文エラー）`、`Runtime Error（実行時エラー）`、`Invalid Value（不正値）` として処理され、フィルタ本体をクラッシュさせません。

## フェーズ4: 標準関数

スクリプトへ次の関数を公開しています。角度の単位はラジアンです。

- `aim()`: `atan2(target_y - origin_y, target_x - origin_x)` を返す
- `deg(degrees)`: 度をラジアンへ変換する
- `quantize(angle, step)`: 角度を最も近い `step` の倍数へ丸める
- `polar(angle, radius)`: `{ x, y }` を持つ極座標変換結果を返す

`quantize`は量子化境界を越えるまで同じ角度を返します。例えば刻み幅5.625度の場合、42.18度は39.375度、42.19度は45度へ量子化されます。これら4関数はRust単体とRhaiスクリプト経由の両方でテストしています。

## フェーズ5: 弾幕プリセット

4種類とも専用の描画コードを持たず、通常の弾幕スクリプトとして同じ `ScriptEngine → Bullet/Wave Runtime → BulletState → Renderer` 経路を通ります。

- 自機狙い奇数5方向: 5発の中央弾が `aim()` の方向を向き、左右へ8度間隔で展開する
- 角度量子化自機狙い: 5.625度単位の量子化境界を越えるまで中央弾の角度が変化しない
- 速度差リング: 24方向それぞれへ速度280・420・560の3発を発射し、時間経過で3つのリングへ分離する
- 混成弾幕: 1 Waveあたり5方向×3速度の15発を生成し、量子化自機狙いへWave単位の位相変化を加える

自動テストでは混成弾幕のWave 0が中央45度、Wave 1が位相分だけ進んだ48度となること、および各Waveが15発で速度320・460・600の3層になることまで確認しています。

## フェーズ6: 安全制限と向きオプション

### 自機座標モード

`手動座標`では従来どおりターゲット X / Yを使用します。`レイヤー最新座標`では、自機レイヤーで現在時刻に有効な画像オブジェクトの最終出力座標を仮想自機座標として使用します。

内部では `aviutl2-rs` の `FilterProcVideo::get_image_object(layer, 0.0)` と `get_output_image_param` を使用します。取得したシーン座標から弾幕オブジェクト自身のシーン座標を引き、弾幕のローカル座標へ変換します。

- UIの自機レイヤーは1始まり、APIへ渡すときは0始まりへ変換する
- 指定レイヤーに現在有効な画像オブジェクトがない場合は、ターゲット X / Yへフォールバックする
- 弾幕オブジェクト自身と同じレイヤーを指定した場合は、再帰評価を避けるため手動座標へフォールバックする

### 弾の向き

- 向き設定は `進行方向を向く` のtrue/falseだけです
- trueの場合は、`motion`を現在ageと微小にずらしたageで評価し、座標差から進行方向を計算します
- trueの場合はスクリプトの回転値を進行方向で上書きします。画面上の速度ベクトルを、上向きが頂点である入力図形のローカル座標へ `atan2` で変換し、固定角度の加算は行いません
- 回転は描画状態だけに適用し、自機狙い角度・速度・座標計算には影響しません
- falseの場合はスクリプトの `rotation` をそのまま使用します

進行方向は現在の `t / age / wave / i` から直接求めます。前フレームの回転状態は保存しないため、途中再生と逆シークでも再現できます。

### 安全制限

- 全生存Wave合計で最大4096発
- 最大同時256 Wave
- 弾の寿命は最大30秒
- 1フレームあたり最大65,536回のスクリプト評価
- Custom Scriptは最大64 KiB、式の深さにも上限を設定
- Wave内で変動する `count`、NaN、Infinity、負の速度、0以下の寿命、不正なscale/alphaを拒否

上限超過や不正値は `Invalid Value（不正値）`、構文エラーは `Parse Error（構文エラー）`、実行中の失敗は `Runtime Error（実行時エラー）` として処理します。

## 現在のプロトタイプ範囲

後続フェーズの土台も同じ共通ランタイム上に実装済みです。

- Rhaiの `spawn {}` / `motion {}` スクリプト
- `aim`、`deg`、`quantize`、`polar` などの標準関数
- 入力依存の決定論的乱数 `rand(seed, wave, i, salt)`
- 4種類のプリセットとカスタムスクリプトを同一ランタイムで評価
- 最大4096発、最大同時256 Wave、寿命上限30秒、1フレーム最大65,536回のスクリプト評価、スクリプト最大64 KiB
- Parse Error、Runtime Error、Invalid Valueをクラッシュさせずエラーとして返却

## `au2`による実機確認

このリポジトリでは `.tools\au2.exe` を使用します。`aviutl2-cli 0.11.2`では、`au2 dev`に相当するコマンド名は `au2 develop` です。

初回準備:

```powershell
.tools\au2.exe prepare:aviutl2
.tools\au2.exe prepare:artifacts --profile release --force
```

開発用AviUtl2を起動:

```powershell
.tools\au2.exe develop --profile release
```

`aviutl2.toml`により、`target\release\kantandanmaku.dll` が開発環境の `Plugin\kantandanmaku.auf2` として配置されます。

起動後は図形または画像オブジェクトへ「弾幕生成フィルタ」を適用し、次を確認します。

1. 入力画像が複数の弾として描画される
2. 同じフレームへ繰り返し移動しても位置が変わらない
3. 途中フレームから表示しても弾幕が成立する
4. 後ろから前へシークしても同じ位置へ戻る
5. ターゲット X / Yを変更すると自機狙い方向が変わる
6. 自機座標モードをレイヤー最新座標にすると、指定レイヤーの移動へ自機狙い方向が追従する
7. 進行方向を向くと、矢印・三角形の頂点が進路の外側を向く

配布パッケージの生成:

```powershell
.tools\au2.exe release --profile release
```
